# MLH · Best Domain Name from GoDaddy Registry

The MLH prize for a domain registered through GoDaddy Registry. Copied Oct 24, 2026 from Devpost and MLH's prizes page. Hub: [[cal-hacks-13]] · Spec: [[cindia-spec]] · v2 brief: the repo's `docs/v2/brief.md`

## At a glance

- **Prize (Devpost):** a Digital Gift Card. No cash value is listed.
- **What it asks:** register the project's domain name with GoDaddy Registry.
- **Where to claim it:** MLH's prizes page (https://www.mlh.com/events/prizes) has a "Build with GoDaddy Registry" link, `mlh.link/GoDaddyRegistry`, and a "Claim promo code" button. The page doesn't say which extensions are free or for how long, and a fetch couldn't open the link's target. Check in a browser.
- **MLH at the venue:** the GitHub Copilot workshop (Fri 6:00 to 7:00 PM, Gate 3, missed), cookie decorating (Sat 7:00 to 8:00 PM, Gate 4) and the MLH Hardware Lab. The Hacker Guide asks every project to follow the MLH Code of Conduct.
